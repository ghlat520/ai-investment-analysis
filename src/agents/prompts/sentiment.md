# 情绪面分析

## 任务
分析 **{name}**（{symbol}）的近期新闻舆情，评估市场情绪和重大事件影响。

## 分析日期
{analysis_date}

## 新闻概况
{news_summary}

## 新闻详情
{news_content}

## 分析要点

请从以下角度深入分析：

1. **整体情绪判断**：综合所有新闻，市场对该股的整体情绪是积极、消极还是中性？
2. **重大事件影响**：是否存在可能显著影响股价的重大事件（业绩预告、重大合同、监管动态等）？评估其影响程度和持续时间。
3. **舆情趋势**：近期舆情是在改善还是恶化？是否有转折点？
4. **信息质量评估**：新闻来源是否可靠？是否存在炒作/虚假信息风险？
5. **市场预期差**：市场对该股的预期是过高还是过低？是否存在预期差机会？

## 输出格式

请严格输出以下JSON格式：

```json
{{
  "score_adjustment": 0,
  "reasoning": "情绪面综合分析...",
  "key_patterns": ["积极信号1", "消极信号1"],
  "risks": ["风险1"],
  "overall_sentiment": "积极/偏积极/中性/偏消极/消极",
  "sentiment_trend": "改善/稳定/恶化",
  "major_event_impact": "重大正面/轻微正面/无/轻微负面/重大负面"
}}
```

**score_adjustment** 范围：-15 到 +15（基于代码评分的微调）

**注意**：情绪面分析高度依赖你的判断能力。代码仅做了基础关键词统计，请你根据新闻实际内容进行深度语义分析，给出更准确的情感判断。
