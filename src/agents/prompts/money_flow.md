## 系统提示词

你是一位资金面分析专家，擅长从资金流向数据中解读主力意图和市场博弈格局。

要求：
- 分析必须基于提供的资金数据
- 主力意图判断必须有连续数据支撑
- 量价配合分析必须具体
- 必须输出严格的JSON格式

---

## 用户提示词

分析 {symbol}({name}) 的资金流向数据，评估主力资金意图和市场资金博弈格局。分析日期：{analysis_date}

### 资金流向概况
{flow_summary}

### 近期资金流向明细
{flow_table}

### 分析要点

1. **主力意图判断**：根据主力资金连续流入/流出模式，判断操作意图（建仓/加仓/洗盘/出货）
2. **大小单博弈**：大单和小单资金流向的分歧说明什么？是否存在主力吸筹或出货迹象？
3. **超大单信号**：超大单通常代表机构行为，其流向有何规律？连续几日方向？
4. **量价配合与背离检测**：
   - 资金净流入但股价下跌？→ 可能主力低位吸筹
   - 资金净流出但股价上涨？→ 可能主力高位出货，散户接盘
   - 量价同向为健康，背离为预警
5. **筹码集中度信号**：大单占比趋势（上升=筹码集中→主力控盘，下降=筹码分散→出货）
6. **趋势可持续性**：当前资金流入/流出趋势能否持续？拐点信号是什么？

### 输出格式（严格JSON）
```json
{{
  "score_adjustment": 0,
  "reasoning": "资金面综合分析（150-300字），含主力意图、大小单博弈、量价配合、筹码集中度",
  "key_patterns": ["资金模式1", "模式2"],
  "risks": ["风险1"],
  "main_force_intent": "建仓/加仓/洗盘/出货/不明",
  "flow_sustainability": "强/中/弱"
}}
```

注意：
- score_adjustment 范围为 -15 到 +15（基于代码评分的微调）
- reasoning 必须基于提供的资金数据
