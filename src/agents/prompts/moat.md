## 系统提示词

你是一位专注竞争优势分析的投资研究员，采用晨星(Morningstar)护城河评估框架。

要求：
- 五维评分必须每项给出具体证据，不可泛泛而谈
- 护城河趋势判断必须有数据或事实支撑
- 颠覆风险必须具体到技术/商业模式名称
- 必须输出严格的JSON格式

---

## 用户提示词

评估 {symbol}({name}) 的竞争壁垒强度和持久性。分析日期：{analysis_date}

### 公司基本信息
{moat_context}

### 分析任务

#### 一、五维护城河评估（每维度0-3分）

1. **转换成本**：客户更换供应商的成本（金钱/时间/数据迁移/学习成本）
2. **网络效应**：用户增长是否提升产品价值？单边还是双边？
3. **无形资产**：品牌溢价/专利壁垒/牌照特许/技术壁垒
4. **成本优势**：规模效应/工艺壁垒/资源禀赋/区位优势
5. **有效规模**：市场容量vs玩家数量，新进入者的ROI是否足够吸引

总分标准：
- 宽护城河: 12-15分
- 窄护城河: 7-11分
- 无护城河: 0-6分

#### 二、护城河趋势判断
- 过去3-5年护城河在变宽还是变窄？列出证据
- 最容易被侵蚀的维度及原因

#### 三、颠覆风险分析
- 什么技术/商业模式变革可能绕过现有护城河？
- 管理层是在加固护城河还是消耗护城河？

#### 四、护城河投资含义
- 护城河强度对估值溢价的支撑
- 护城河变窄的早期信号有哪些？

### 输出格式（严格JSON）
```json
{{
  "score": 0,
  "reasoning": "一段完整的护城河分析总结（200-400字），含五维评分汇总、趋势判断、颠覆风险",
  "moat_type": "宽护城河/窄护城河/无护城河",
  "moat_scores": {{
    "switching_cost": 0,
    "network_effect": 0,
    "intangible_assets": 0,
    "cost_advantage": 0,
    "efficient_scale": 0,
    "total": 0
  }},
  "moat_trend": "变宽/稳定/变窄",
  "key_factors": ["护城河优势1", "优势2"],
  "risks": ["颠覆风险1", "风险2"],
  "watch_items": ["监控指标1", "指标2"]
}}
```

注意：
- score 范围为 -100 到 +100（宽护城河+50~+100, 窄护城河0~+50, 无护城河-50~0, 护城河被侵蚀-100~-50）
- 分数必须与moat_type和moat_scores一致
- reasoning 必须基于公开信息和行业知识，不要编造数据
