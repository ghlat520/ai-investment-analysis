## 核心洞察

> **这个系统的本质不是"AI预测股价"，而是"系统化投资分析框架"。**

它的价值在于：
1. **强制执行完整分析流程**（避免遗漏）
2. **显式化隐性知识**（代码规则）
3. **处理矛盾信号**（多空辩论）
4. **提供可追溯决策依据**（溯源链）

但它**无法替代人类判断**，只能作为"投研助手"而非"投资决策者"。

## 一、核心优势（按重要性排序）

### 1. 代码优先 + LLM辅助的混合架构

**具体表现**：
- 量化Agent（technical/money_flow）：80%代码计算，20%LLM微调
- 混合Agent（fundamental/valuation/sentiment）：60%代码，40%LLM
- LLM主导Agent：已引入量化锚点约束（moat的毛利率/ROE锚点）

**对投资决策的价值**：将确定性高的部分交给代码（如PE计算、ROE年化），不确定性高的部分交给LLM（如护城河定性判断）。鼎龙案例证明：目标价代码算39元 vs LLM输出3.19元 → **代码必须优先**。

```python
# src/agents/analysts/moat.py:216-220
if abs(score - anchor_score) > 30:
    clamped = max(anchor_score - 30, min(anchor_score + 30, score))
    logger.info(f"[moat] 评分{score}偏离锚点{anchor_score}超过30分，修正为{clamped}")
    score = clamped
```

### 2. 三层渐进式融合机制

**具体表现**：
- **Layer1 量化加权**：按市场环境（牛/熊/震荡）动态调整权重
- **Layer2 规则否决**：ST股封顶-50分，退市风险-100分，次新股跳过
- **Layer3 LLM辩论**：多空论据对等呈现，处理矛盾信号

**对投资决策的价值**：模拟人类投委会决策流程。量化层处理确定性，规则层处理极端风险，辩论层处理不确定性。

```yaml
# config/weights.yaml - 牛市vs熊市权重对比
bull:
  technical: 0.16    # 牛市重视趋势
  money_flow: 0.16   # 牛市重视资金
bear:
  fundamental: 0.14  # 熊市重视价值
  valuation: 0.16    # 熊市重视估值
```

### 3. 数据免疫系统（隐性知识显性化）

**具体表现**：D1-D6规则覆盖常见数据坑：

| 规则 | 处理 | 代码位置 |
|------|------|---------|
| D1 PE负值 | 从百分位计算中排除 | `valuation.py` |
| D2 季报ROE | 自动年化（Q1×4, Q2×2, Q3×4/3） | `fundamental.py` |
| D3 新闻噪声 | 过滤通用榜单 | `sentiment.py` |
| D5 行情陈旧 | 生成警告 | `analysis_service.py` |

**对投资决策的价值**：这些规则是资深分析师的隐性经验，预置为代码后，每次分析自动应用，无需LLM"自己发现"。

## 五、第一性原理分析摘要

### 投资决策的本质

1. **信息获取**（数据）→ 多源数据 + 研报注入 ✅
2. **信息处理**（分析）→ 9维分析框架 ✅
3. **模式识别**（判断）→ 量化代码 + LLM形态识别 ✅
4. **风险评估**（验证）→ 三层融合 + 交叉验证 ✅
5. **行动决策**（执行）→ 操作策略输出 ✅

### 代码 vs LLM 的本质权衡

| 维度 | 代码计算 | LLM推理 |
|------|---------|---------|
| 确定性 | 100% | 概率性 |
| 可验证性 | 可追溯 | 难审计 |
| 适用场景 | 数值计算、边界条件 | 定性判断、形态识别 |

### 鼎龙教训的本质

**确定性边界必须代码化**
- 目标价：代码算39元 → LLM输出3.19元（错2个数量级）
- 解决：YAML覆写，强制代码值优先

**LLM方差必须有锚点约束**
- Moat评分：多次运行极差44分
- 解决：加入毛利率/ROE锚点，LLM只能在±30分内调整

**复杂业务结构需要分拆估值**
- 鼎龙6条产品线增速不同
- 解决：分业务估值模型
