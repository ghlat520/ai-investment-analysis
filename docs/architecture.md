# 架构总览

## 系统定位

全维度多Agent协作的AI投研助手系统，覆盖A股/港股/美股，支持量化筛选+AI深度分析。

## 数据流

```
数据采集 → PostgreSQL/TimescaleDB → 量化筛选 → LangGraph分析 → 研报+通知
              ↑                                      ↑
           Redis缓存                            LLM路由层
         (行情/LLM缓存)                    (多provider+成本追踪)
```

### 关键数据流节点

1. **数据采集**：auto-fallback数据源 → 标准化 → 入库
2. **量化筛选**：全市场数据 → 多因子评分 → Top N
3. **Agent分析**：候选标的数据 → 6个Agent并行 → 各维度信号
4. **决策融合**：6路信号 → 动态权重 + 规则否决 + LLM仲裁 → 综合决策
5. **研报生成**：融合决策 + 各Agent详细分析 → 结构化报告

## 市场适配层

```python
MarketAdapter(ABC)
├── AShareAdapter   # A股：akshare/efinance/tushare/pytdx/baostock
├── HKStockAdapter  # 港股：yfinance + 港交所数据
└── USStockAdapter  # 美股：yfinance + SEC数据
```

每个市场适配器声明：
- 支持哪些Agent（如美股无北向资金数据）
- 特有数据源（如A股北向资金、美股13F持仓）
- 交易日历和时区

## 信号仲裁机制

### 三层仲裁

1. **量化层**：动态权重加权
   - 牛市权重：技术面30% + 资金面25% + 情绪面20% + 基本面10% + 估值10% + 产业链5%
   - 熊市权重：基本面25% + 估值25% + 技术面20% + 资金面15% + 产业链10% + 情绪面5%
   - 震荡权重：均衡分配

2. **规则层**：硬性否决
   - 退市风险 → 强制卖出
   - ST/*ST → 降低信号
   - 停牌中 → 跳过

3. **LLM层**：融合Agent推理仲裁
   - 输入各Agent信号 + 矛盾分析
   - 输出最终决策 + 推理过程

## 技术选型

| 领域 | 选型 | 理由 |
|------|------|------|
| Agent框架 | LangGraph | fan-out/fan-in、状态精确控制 |
| LLM调用 | LangChain ChatModel | 统一接口适配多provider |
| 数据处理 | pandas + numpy + ta-lib | 金融标准库 |
| 数据采集 | akshare + efinance + yfinance | 复用auto-fallback模式 |
| 数据库 | PostgreSQL + TimescaleDB | 结构化+时序+JSONB |
| ORM | SQLAlchemy 2.0 | 异步+类型安全 |
| 缓存 | Redis | LLM响应缓存 |
| 配置 | Pydantic Settings | 类型安全配置 |
| 调度 | APScheduler | 轻量Python原生 |
| 包管理 | uv | 快速现代 |
