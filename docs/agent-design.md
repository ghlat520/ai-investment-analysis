# Agent 详细设计

## 统一输出协议

每个分析Agent的输出遵循统一协议：

```python
class AgentSignal:
    agent_name: str           # Agent标识
    signal_score: int         # -100 ~ +100（强烈卖出 ~ 强烈买入）
    confidence: float         # 0.0 ~ 1.0
    reasoning: str            # 推理过程
    key_factors: list[str]    # 关键因素列表
    risks: list[str]          # 风险提示
    data_quality: float       # 数据质量评分 0.0 ~ 1.0
    metadata: dict            # Agent特有的结构化数据
```

### 信号分数语义

| 分数区间 | 语义 | 对应操作 |
|---------|------|---------|
| +80 ~ +100 | 强烈看多 | 建仓/加仓 |
| +40 ~ +79 | 看多 | 逐步建仓 |
| +1 ~ +39 | 偏多 | 观察/小仓位 |
| -39 ~ 0 | 中性偏空 | 观望 |
| -79 ~ -40 | 看空 | 减仓 |
| -100 ~ -80 | 强烈看空 | 清仓 |

## Agent 1: 技术面分析 (TechnicalAnalyst)

### 职责
分析价格趋势、技术形态、量价关系，给出短期交易信号。

### 输入数据
- 日线行情（OHLCV）：最近250个交易日
- 分钟线（可选）：最近5个交易日

### 分析维度

| 子维度 | 指标 | 权重 | 实现方式 |
|--------|------|------|---------|
| 趋势 | MA5/10/20/60/120/250排列 | 25% | 代码 |
| 动量 | MACD金叉/死叉、RSI超买超卖 | 20% | 代码 |
| 量价 | 量能放大/萎缩、量价背离 | 20% | 代码 |
| 形态 | 突破/头肩底/双底等 | 15% | LLM |
| 支撑阻力 | 关键价位识别 | 10% | 代码+LLM |
| 乖离率 | 均线偏离度 | 10% | 代码 |

### 计算指标（代码部分）
```
- MA: 5, 10, 20, 60, 120, 250日均线
- MACD: (12, 26, 9) 标准参数
- RSI: 6日、14日
- KDJ: (9, 3, 3)
- BOLL: 20日布林带
- 量比: 5日均量比较
- 换手率: 流通盘计算
```

### LLM分析（20%）
输入技术指标计算结果，LLM综合判断：
- 多指标共振信号
- K线形态识别
- 关键价位和突破确认

### 输出 metadata
```python
{
    "ma_arrangement": "多头排列/空头排列/缠绕",
    "macd_signal": "金叉/死叉/顶背离/底背离",
    "rsi_level": 65.3,
    "volume_trend": "放量/缩量/平量",
    "key_support": 25.50,
    "key_resistance": 28.80,
    "pattern": "突破前高/头肩底/无明显形态"
}
```

## Agent 2: 基本面分析 (FundamentalAnalyst)

### 职责
评估公司财务质量、盈利能力、增长潜力。

### 输入数据
- 最近12个季度财报（3年）
- 年报摘要
- 行业平均值

### 分析维度

| 子维度 | 指标 | 权重 | 实现方式 |
|--------|------|------|---------|
| 盈利能力 | ROE、ROA、毛利率、净利率 | 30% | 代码 |
| 成长性 | 营收增速、净利增速、CAGR | 25% | 代码 |
| 财务健康 | 资产负债率、流动比率、现金流 | 20% | 代码 |
| 质量 | 经营现金流/净利润、应收周转 | 15% | 代码 |
| 综合评估 | 杜邦分析、财报质量疑点 | 10% | LLM |

### 计算指标（代码部分）
```
盈利: ROE, ROA, 毛利率, 净利率, 扣非净利率
成长: 营收YoY, 净利YoY, 3年CAGR
健康: 资产负债率, 流动比率, 速动比率
现金: 经营现金流/净利润, 自由现金流
周转: 应收周转天数, 存货周转天数
```

### LLM分析（40%）
- 财报异常识别（大额减值、关联交易）
- 盈利质量评估
- 行业竞争地位分析

### 输出 metadata
```python
{
    "roe": 15.3,
    "roe_trend": "上升/稳定/下降",
    "revenue_growth_yoy": 23.5,
    "profit_growth_yoy": 18.2,
    "debt_ratio": 45.6,
    "cash_flow_quality": "优/良/中/差",
    "financial_alerts": ["应收账款快速增长", "商誉占比过高"]
}
```

## Agent 3: 估值分析 (ValuationAnalyst)

### 职责
判断当前估值水平是否合理，评估安全边际。

### 输入数据
- 当前PE/PB/PS
- 历史PE/PB分位数（5年）
- 行业平均PE/PB
- 盈利预测（如有）

### 分析维度

| 子维度 | 指标 | 权重 | 实现方式 |
|--------|------|------|---------|
| 绝对估值 | PE/PB/PS当前值 | 25% | 代码 |
| 历史分位 | PE/PB历史百分位 | 25% | 代码 |
| 行业对比 | vs 行业平均/中位数 | 20% | 代码 |
| PEG | PEG = PE / 盈利增速 | 15% | 代码 |
| 综合评估 | 估值合理性+催化剂 | 15% | LLM |

### 输出 metadata
```python
{
    "pe_ttm": 25.3,
    "pe_percentile_5y": 0.35,  # 处于5年35%分位
    "pb": 3.2,
    "pb_percentile_5y": 0.45,
    "peg": 1.2,
    "industry_pe_avg": 30.5,
    "valuation_level": "低估/合理/高估/严重高估"
}
```

## Agent 4: 资金面分析 (MoneyFlowAnalyst)

### 职责
追踪主力资金、北向资金、融资融券等智慧资金动向。

### 输入数据
- 主力资金流向（近20日）
- 北向资金持仓变化
- 融资融券余额变化
- 大宗交易数据

### 分析维度

| 子维度 | 指标 | 权重 | 实现方式 |
|--------|------|------|---------|
| 主力资金 | 主力净流入/出 | 30% | 代码 |
| 北向资金 | 持仓变化、加仓/减仓 | 25% | 代码 |
| 融资融券 | 融资余额变化趋势 | 20% | 代码 |
| 大宗交易 | 折溢价率、频率 | 15% | 代码 |
| 综合判断 | 资金一致性分析 | 10% | LLM |

### 输出 metadata
```python
{
    "main_force_net_inflow_5d": 1.5e8,  # 5日主力净流入
    "main_force_trend": "持续流入/流出/分歧",
    "northbound_change_5d": 2.3e6,  # 北向5日变化（股）
    "margin_balance_trend": "增加/减少/稳定",
    "block_trade_premium": -2.5  # 大宗交易折价率%
}
```

## Agent 5: 情绪面分析 (SentimentAnalyst)

### 职责
分析市场情绪、新闻舆情、分析师评级。

### 输入数据
- 最新新闻（搜索引擎获取）
- 分析师评级（如有）
- 市场热度指标

### 分析维度

| 子维度 | 指标 | 权重 | 实现方式 |
|--------|------|------|---------|
| 新闻情绪 | 正面/负面/中性分类 | 35% | LLM |
| 事件驱动 | 重大事件识别+影响评估 | 25% | LLM |
| 分析师 | 评级变化、目标价 | 20% | 代码+LLM |
| 市场热度 | 搜索热度、讨论量 | 20% | 代码 |

### 搜索维度（复用SearchService模式）
1. `{股票名} 最新新闻 2026` — 近期动态
2. `{股票名} 业绩 季报 年报` — 业绩相关
3. `{股票名} 风险 诉讼 处罚` — 风险事件
4. `{股票名} 行业 政策` — 行业政策
5. `{股票名} 分析师 评级 目标价` — 机构观点

### 输出 metadata
```python
{
    "news_sentiment": "正面/中性/负面",
    "news_count": 15,
    "key_events": ["获得大额订单", "高管增持"],
    "analyst_consensus": "买入/增持/中性/减持",
    "analyst_target_price": 35.0,
    "risk_events": []
}
```

## Agent 7: 决策融合 (FusionAgent)

### 职责
整合6个分析Agent的信号，产出最终投资决策。

### 输入
- 6个Agent的 `AgentSignal`
- 市场环境判断（牛/熊/震荡）

### 仲裁逻辑

#### Step 1: 量化加权
```python
# 根据市场环境选择权重方案
weights = get_market_weights(market_regime)
weighted_score = sum(signal.score * signal.confidence * weight
                     for signal, weight in zip(signals, weights))
```

#### Step 2: 规则否决
```python
if stock.is_st or stock.delisting_risk:
    final_signal = min(final_signal, -50)
if stock.is_suspended:
    skip = True
```

#### Step 3: LLM仲裁
当信号矛盾（如技术面+80、基本面-60）时，LLM综合推理：
- 分析矛盾原因
- 判断哪个维度更可信
- 给出最终决策

### 输出
```python
{
    "final_score": 45,
    "final_action": "建仓",
    "confidence": 0.72,
    "position_pct": 30,  # 建议仓位比例
    "stop_loss_pct": -8,
    "take_profit_pct": 15,
    "reasoning": "技术面突破+资金面流入确认，但估值偏高需控制仓位",
    "signal_summary": {
        "technical": +65,
        "fundamental": +30,
        "valuation": -20,
        "money_flow": +55,
        "sentiment": +40,
        "industry": +25
    },
    "conflicts": ["估值偏高与技术面突破矛盾"],
    "conflict_resolution": "短期动量优先，设置止损保护"
}
```

## Agent 8: 研报生成 (ReportGenerator)

### 职责
将融合决策和各Agent分析结果，生成结构化投研报告。

### 报告结构

```markdown
# {股票名称}({代码}) 投研分析报告

## 综合评级：⭐⭐⭐⭐（看多）
- 综合评分：+45/100
- 置信度：72%
- 建议操作：建仓（30%仓位）
- 止损位：¥XX.XX（-8%）
- 目标位：¥XX.XX（+15%）

## 核心逻辑
[1-2段总结]

## 各维度分析
### 技术面（+65）
...
### 基本面（+30）
...
### 估值（-20）
...
### 资金面（+55）
...
### 情绪面（+40）
...

## 风险提示
- ...

## 数据来源与时效性
- 行情数据截至：2026-02-11
- 财务数据：2025Q3
- 新闻数据：最近7天
```

### 输出格式
- **Markdown**：默认输出，用于通知推送
- **HTML/PDF**：Phase 3支持，用于正式研报
